Python Desktop Calculator
 A simple and clean desktop calculator application built using Python and the `tkinter` library.

 Features
- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Square root (√) calculation with precision rounding
- Percentage calculation and sign toggling (+/-)
- Clear and user-friendly graphical user interface (GUI)

 Technologies Used
- Python
- Tkinter
- Math Module
